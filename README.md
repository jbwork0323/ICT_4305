<p>We will be following Java’s official package naming conventions for directories and files,
which means all folders and files must be named as lowercase values with words
separated by an underscore. For example, if I had a folder named My Documents, in
Java I would name this folder my_documents. It might be easier to create the module
folders as we move through the course.
• Module folders (i.e., module_<number>)
• Each module will have its own folder with its associated assignment files
• For example:
• module_1
• assignment_1_use-cases
• assignment_1_group_write_up
• assignment_3
• module_2
• assignment_1_parking_use_cases</p>
